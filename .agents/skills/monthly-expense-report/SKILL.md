# 月度费用报销表格填写技能

## 概述

本技能用于根据用户提供的发票信息，按照规定规则填写月度费用报销申请表（出差专用，表单编号 FIN-01-0001-02B）。

---

## 第一步：识别发票 & 一次性确认所有不确定项

### 发票识别规则

**费用类型【铁律：必须看发票的货物明细，决不能仅看发票抬头/销售方名称】**：
  - **京东/天猫电商发票**：如果销售方是京东（如“武汉京东金德贸易有限公司”、“武汉京东德瑞贸易有限公司”）或天猫，**绝对禁止**直接归类为“运费”或“快递费”！你必须查看发票正文货物/劳务“项目名称”明细：
    - 若明细是“矿泉水”、“百岁山”、“饮料”、“茶叶”、“零食”等，必须归类为 **`“其它”`**（或杂费），`client` 填 `购买百岁山矿泉水`（或其他实际货物）；
    - 若明细是“打印纸”、“硒鼓”、“文具”、“键盘”、“办公用品”等，必须归类为 **`“文具用品”`**（或办公费），`client` 填 `购买办公文具`；
    - **只有**明细里明确写着“运费”、“配送费”、“快递服务”时，才能分类为 **`“运费”`**。
  - 例：销售方是"深圳通用移动通信"，但项目是"通信服务费" → 电话费
  - 例：销售方是"滴滴出行"，项目是"网约车服务" → 交通费
  - 例：销售方是任何餐饮公司，项目是"餐饮服务" → 交际费或餐费（看场景）
- 交际费 vs 餐费的判断：
  - 交际费：与客户共同用餐、餐前后娱乐
  - 餐费：出差途中个人餐饮（火车/机场/目的地/出发返回当天）

**金额读取**：⚠️ 必须使用发票右下角的**含税小写合计金额**（即最终应付总价）
  - ❌ 错误：使用不含税金额、税额、单价等中间数字
  - ✅ 正确：使用"小写：¥XXX.XX"或"合计：¥XXX.XX"那一栏的数字
  - 发票上通常同时显示不含税金额和含税合计，务必取含税合计

### 一次性确认原则（重要）
识别完所有发票后，如有任何不确定的情况，**必须将所有疑问汇总为一个菜单，一次性让用户选择**，不允许多轮反复询问。

典型需要确认的情形：
- 两张发票信息完全相同（重复上传 vs 两笔独立消费）
- 发票销售方与费用类型不明显对应
- 多张同类发票是否合并为一行
- 某笔金额归属交际费还是餐费不明确
- 发票归属月份不明确（如跨月发票）

**格式要求**：用 `ask_user_input_v0` 工具，把所有问题一次呈现，每个问题配 2-4 个选项，用户一次点完。

## 补充规范：大模型数据提取规范 (JSON Output)

请从上传的发票/行程单等材料中提取全部明细，并返回纯 JSON 格式：

### 提取字段要求

* `date`：发生日期或开票日期 (格式统一为 YYYY/MM/DD)
* `client`：消费商户/销方名称（如果是交通票如滴滴填 "滴滴出行"，如果是餐饮填餐饮商户如 "乡厨餐饮"，日常行政费用填写具体用途）
* `amount`：消费总金额 (RMB，数值格式)
* `type`：AI 推荐的费用科目，必须是以下之一: `["交通費", "手機電話費", "郵電費", "書報雜誌", "文具用品", "印刷", "水電瓦斯費", "交際費", "運費", "郵費", "修繕費", "其它", "飞机票", "机票", "火车票", "高铁", "住宿"]`
* `people`：交际费人数（数值格式，如 3）。如果是交际类型且能提取人数则写提取值，否则默认填 3。非交际类型填 0。
* `from`：出发城市（仅在出差大交通如机票/火车票时填写，否则为空）
* `to`：到达城市（仅在出差大交通如机票/火车票时填写，否则为空）
* `summary`：摘要/备注（如果是交际费，写明用餐人数如"3人"；如果是大交通，写明目的地；其他零散发票写明具体用途）

### JSON 示例格式

```json

    {

      "client": "乡厨餐饮服务店",
```

## 第二步：动态决定列结构（严禁空列）


### 核心原则：有数据才有列，无数据必须删列

**模板原始列顺序**（转换后xlsx中）：
```
A:序  B:日期  C:産品線  D:比例  E:客戶/項目  F:由  G:到  H-J:摘要(合并)  K:貨幣
L:电话费  M:交通费  N:高铁/飞机票  O:住宿费  P:餐费  Q:交际费  R:礼物卡  S:小計
```

### 处理步骤
1. 扫描当月所有发票，确定实际用到的费用列
2. 在模板中**删除所有无数据的费用列**（从右往左逐列删除，避免索引错位）
3. 保留有数据的列，顺序不变
4. 小计公式和总计公式必须根据删列后的实际列范围重新计算

### 删列代码模式（务必从右往左删）
```python
# 先解除涉及费用列区域的所有合并单元格（N7:S7、H17:Q17等）
ranges_to_unmerge = []
for mr in ws.merged_cells.ranges:
    if any(c in str(mr) for c in ['N','O','P','Q','R','S']):
        ranges_to_unmerge.append(str(mr))
for r in ranges_to_unmerge:
    ws.unmerge_cells(r)

# 从右往左删除无数据列（示例：删礼物卡R、餐费P、住宿O、高铁N）
ws.delete_cols(18)  # R 礼物卡
ws.delete_cols(16)  # P 餐费（删R后原P还是16）
ws.delete_cols(15)  # O 住宿
ws.delete_cols(14)  # N 高铁/飞机票
# 删完后重新确认各列实际位置，再填数据和公式
```

### 可选费用列清单（历史出现过的，按实际增减）
电话费、交通费、高铁/飞机票、住宿费、餐费、交际费、礼物卡、体检费、办理通行证、鼠标键盘等办公用品

> **⚠️ 严禁**：填完数据后留有空列。生成后须检查所有费用列，无数据的列必须已删除。

## 第三步：行排列规则

行顺序严格遵守以下规则：

1. **第1行**：电话费（固定第一）
2. **第2行**：交通费（固定第二）
3. **第3行起**：其余费用按**发票开票日期从早到晚**排序

序号从 1 开始连续递增，不跳号。

---

## 第四步：各字段填写规则（列位置以删列后实际为准）

### 固定字段（每行都一样）
| 字段 | 值 |
|------|----|
| 費用歸屬（産品線） | WHPA |
| 費用歸屬（産品線比例） | 100%（填 1） |
| 貨幣 | RMB |

### 日期
- 填发票的**开票日期**
- 电话费和交通费：填当月账单日期（通常为月初固定日，用户提供）

### 客戶/項目
| 费用类型 | 填写内容 |
|----------|----------|
| 电话费 | `X月电话费用`（如"10月电话费用"） |
| 交通费 | `X月交通费`（如"10月交通费"） |
| 出差（高铁/飞机/住宿/途中餐费） | 填**拜访目的地的客户名称**（如"拜访深圳精智达"） |
| 交际费（与客户吃饭/娱乐） | 填**发票开票的餐厅/商家名称**（如"乡厨餐饮"） |
| 其他（体检费、礼物卡等） | 填费用的具体描述（如"客户礼品卡"） |

### 由 / 到（出发地 → 目的地）
- **仅出差行填写**，填火车票/机票上的出发站和到达站
- 每次出差通常产生两行：去程一行、返程一行
- 交际费、电话费、交通费等**不填**由/到

### 摘要/備註
| 费用类型 | 填写内容 |
|----------|----------|
| 电话费 | `电话费` |
| 交通费 | `交通费` |
| 交际费 | 填**人数**（如"3人"、"5人"） |
| 出差行 | **留空** |
| 其他 | **留空** |

### 费用金额
- 每张发票的金额填入**对应的费用列**
- 同一行（同一次出差或同一天）可以有多列金额（如火车票+餐费+住宿费同一行）
- **交际费**和**个人餐费**区别：
  - 交际费：与客户一起用餐、或餐前后娱乐活动费用
  - 餐费：出差途中个人餐饮（火车上、机场、目的地、出发当天、返回当天）

### 小計
每行末尾填该行所有金额之和（使用 Excel 公式 `=SUM(对应列)`）

### 总計（最后汇总行）
所有小计行的合计（使用 Excel 公式 `=SUM(小计列)`）

---

## 第五步：出差行合并规则

同一次出差（同一天、同一段路程）的发票尽量合并到**一行**：
- 例：武汉→深圳当天，有火车票 599元 + 餐费 59元 + 住宿 495元 → 合并为一行，客户名称为拜访目的地客户
- 不同天、不同路段分开写行

## 第六步：生成 Excel 文件

使用 `openpyxl` 库生成 .xlsx 文件，保留原模板格式（如用户提供了模板文件，在模板基础上填写）。

### 关键技术要点
- 用 LibreOffice 将 .xls 模板转为 .xlsx：`libreoffice --headless --convert-to xlsx --outdir /home/claude/ template.xls`
- 使用 `load_workbook` 加载转换后的 xlsx，在 PHK sheet 上操作
- **先删无数据列，再填数据，再写公式**（顺序不能错）
- 删列后必须重新确认各费用列的实际列号，小计/总计公式范围据此动态生成
- 日期格式：统一使用 `YYYY/MM/DD`（申请日期和数据行日期都用此格式）
- 列宽：申请日期所在列宽度至少 14，数据行日期列（B列）宽度至少 12，避免显示 `####`
- 填写完成后运行 `python /mnt/skills/public/xlsx/scripts/recalc.py output.xlsx 30` 重新计算
- 输出文件命名：`{月份}月报销表.xlsx`（如 `5月报销表.xlsx`）

### 生成后自检清单
- [ ] 无任何空费用列
- [ ] 序号连续从1开始
- [ ] 小计公式范围与实际费用列一致（无多余列被计入）
- [ ] 总计公式覆盖所有数据行小计
- [ ] 申请日期和所有数据行日期格式为 `YYYY/MM/DD`，列宽足够（不显示 `####`）
- [ ] recalc.py 返回 `"status": "success"`

## 常见边界情况

| 情况 | 处理方式 |
|------|----------|
| 某月无出差 | 只有电话费、交通费行，无高铁/飞机票列 |
| 出差有多段路程 | 每段路程（出发地→目的地）单独一行 |
| 同一天多张交际费发票 | 每张发票单独一行 |
| 特殊费用（体检、礼物卡等） | 新增对应列，客户/项目填费用描述，摘要留空 |
| 用户提供模板文件 | 在模板基础上填写，保留原有格式和公式 |
| 用户未提供模板 | 按标准格式新建，参照 FIN-01-0001-02B 布局 |
